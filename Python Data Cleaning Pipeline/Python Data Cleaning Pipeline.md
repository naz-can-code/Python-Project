## 🧹 Python Data Cleaning Pipeline (pandas)

A reusable data-cleaning pipeline built with **Python** and **pandas**, designed to automate repetitive data-preparation tasks and convert messy CSV files into analysis-ready datasets.

### Features
- Standardizes column names  
- Handles missing values (median/mode/custom)  
- Converts date and numeric columns  
- Removes duplicates  
- Fully configurable  
- Simple plug-and-play class structure  

### How to Run
```bash
python data_cleaning_pipeline.py
